# MediGuide AI

An AI-powered preventive healthcare platform that predicts future health risks, recommends suitable doctors, and provides online consultation support using Artificial Intelligence and modern web technologies.

---

# Project Overview

MediGuide AI is a smart healthcare assistance platform designed to help users understand potential future health risks based on symptoms, lifestyle habits, and medical history. The system uses AI APIs to analyze health-related data and provide preventive suggestions along with doctor recommendations through a user-friendly web interface.

# Installation & Setup

## 1. Clone Repository

```bash
git clone <https://github.com/aarya-saraf/MediGuide-AI>
```

## 2. Move to Project Directory

```bash
cd MediGuide-AI
```

## 3. Install Dependencies

```bash
npm install
```

## 4. Configure Environment Variables

Create a `.env` file and add:

```env
MONGO_URI=your_mongodb_uri
GEMINI_API_KEY=your_gemini_key
```

## 5. Start Backend Server

```bash
npm run server
```

## 6. Start Frontend

```bash
npm run dev
```

## 7. Open in Browser

```txt
http://localhost:3000
```
